# ED note（急診問題導向）

## Intent

科別選「ED 急診（問題導向）」時，病人頁改用問題導向流程，取代 ROS／PE／組套分頁：

1. **問題**：依病人主訴複選（腹痛、發燒、喘、頭暈…共 31 個），並填主訴時間、NRS。
2. **問診**：每個問題各自列出「特徵題＋核心題＋視情況再問」，多個問題**合併**成一份清單；同一題只問一次並標示「共用」，★ 表示紅旗必問。
3. **PE**：依急診病歷表單欄位（GC／HEENT／NECK／CHEST／ABD／BACK／GU／RECTAL／EXT／NEURO）合併；只輸出有按「正常／異常」的項目。
4. **病史**：PMH 快選（勾選會追加相關問診，例如洗腎 → 最後一次透析）、用藥、過敏、TOCC。
5. **病歷輸出**：即時產生 CC／NRS／PI／PH／各 PE 欄位與 ICD-10，顯示字數上限（對應 ERS 表單 maxlength），可逐欄手動修改，一鍵複製「交換文字」供院內 Tampermonkey 腳本帶入。

題庫與規則在 `src/domain/ed/`（純函式，有單元測試）；本 feature 只負責呈現與回傳 immutable `FindingValue`。

6. **檢查**：依已選問題、問診答案、病史、年齡性別，建議 ERS 檢查驗系統的項目（名稱與系統一致、多個問題重複的只出現一次）。標準／加開預設勾選（寧可合理多開），需討論（高輻射、要會診或 VS 同意）預設不勾；醫師可取消、也可手動加入其他項目。勾選結果以 `ORDERS:` 區塊跟著交換文字帶出。

## Non-goals

- 不開立醫囑：只產生「建議」與交換文字，真正放進檢查驗系統待送出格子、以及送出，都在院內 Tampermonkey 腳本與醫師手上。
- 不連線 ERS、不讀病人資料；與院內系統的唯一介面是複製出去的純文字（格式見 `src/domain/ed/chart-text.ts`）。
- 不建議治療（藥物、處置、會診）；只在提醒區列出檢查相關的注意事項。
- 不取代通用的 ROS／PE catalog；其他科別維持原狀。

## Data and integration

- **不改 schema**。答案存在 `patient.findings`，key 一律以 `ed.` 開頭（`edKey` 於 `src/domain/ed/types.ts`）：
  `ed.p.*` 已選問題（`note` 為選取順序）、`ed.h.*` 問診、`ed.pe.*` PE、`ed.pmh.*` 病史、`ed.ctx.*` 時間／NRS／過敏／用藥、`ed.tocc.*`、`ed.ov.*` 手動覆寫、`ed.icd` ICD 勾選與自訂代碼。
  因此 local／Google 同步與三方合併沿用既有 finding 機制，legacy 匯出不會讀到這些 key。
- `buildEdNoteTabs` 回傳 `PatientNoteTab[]`，由 `App.tsx` 在 `isEdPatient(patient)` 時取代標準分頁；急診病人隱藏通用「匯出／列印」。
- 批次動作（「此欄全正常」、「TOCC 全部無」）走 `updatePatientFindings`，只存檔一次。
- 性別／年齡閘門：LMP、懷孕、陰道出血只對女性 12–55 歲（年齡空白也算）顯示。

## 設計依據（歷史資料）

題庫與問題對應依 358 筆急診病歷（CC／PI／PH／PE／Dx）整理：

- 前十大症狀 ICD：R50.9、R42、R10.9、R07.9、R06.00、R53.1、R19.7、R31.9、R33.9、R11.2 都有對應問題，且預設使用 unspecified 症狀碼；診斷性代碼只作為可勾選備選。
- PI 實務是「相關陽性＋重要陰性」，例如發燒必問咳嗽／痰、腹痛、噁心嘔吐腹瀉、解尿、喘、胸痛、頭痛；這些在題庫中就是跨問題共用題。
- PE 欄位長度很緊（HEENT／NECK 僅 60 字），所以正常片語有精簡寫法，仍超過時改成總結句；不會用套版充數未檢查的項目。

## 擴充時

新增問題：在 `problems.ts` 加一筆並引用既有題庫 id；`tests/v2/ed-note.test.ts` 會檢查 id 是否存在、紅旗題是否在詢問清單內、ICD 代碼格式、以及該問題「全部正常」的 PE 是否塞得進表單欄位字數。

## 檢查建議（`src/domain/ed/orders.ts`、`order-rules.ts`）

- `orders.ts`：ERS 檢查驗系統中會被建議的項目（pfkey、系統名稱、檢體、頻率），整理自 2026-10-09 的目錄。**只放 pfkey／名稱／檢體／頻率**，不放價格與選單路徑；系統改名或停用時請重新整理。
- `order-rules.ts`：每個問題一組規則（`core`／`plus`／`ask`），規則依據是北榮急診 PGY 口袋書的各主訴檢查表與急診科常用組套。同一項目被多個問題要求時合併理由、取最高層級；功能重複的項目只留一個（troponin：年輕無風險用 hs-cTnT，其餘 TnI；CXR：站不起來的情境用 portable）。育齡女性在影像前或相關主訴時自動加驗孕。
- **第一輪政策（使用者指定）**：不預設開血液培養與各種培養、床邊超音波、血氣（VBG/ABG）、備血；這些項目沒有任何規則會引用，只能在「其他常用檢查」手動加入（`tests/v2/ed-orders.test.ts` 的 first-round 測試把關）。其餘以口袋書「抽血提醒」的 3-5 類清單為準（所有抽血：CBC/DC、Crea、Na、K、Glu、CRP；再依主訴加項），口袋書沒列的不隨便加，括號（±）項目只在情境成立時出現。
- 性別年齡：驗孕只給 12–55 歲女性（年齡空白視為可能）；「老人」條件 ≥ 65 歲（腹痛的 CK＋TnI 另包含有心血管病史者）；未成年（< 18）CT 一律需討論；可能懷孕時提醒避免不必要的輻射。
- 使用者的勾選／取消存在 `ed.ord.<id>`（`on: true|false`）；沒有覆寫就依層級預設。
- 新增規則時：先確認 `orders.ts` 有該項目；`tests/v2/ed-orders.test.ts` 會檢查規則引用的項目都存在、每個問題都有規則、不重複、互斥項目只出一個。
- 交換格式：`ORDERS:` 放在最後，每行 `pfkey|ERS 名稱|檢體代碼|檢體|頻率`。舊版腳本會忽略它。

## 主訴、問診深度、特別情境、字數精簡（2026-10-10）

- **主訴**（`src/domain/ed/complaints.ts`）：搜尋（標籤＋中英文關鍵字，每個問題都要有關鍵字，測試把關）、常用 12 個置頂、其餘依 全身代謝／心肺／消化／泌尿婦產／神經／五官／外傷皮膚骨科／精神 分組。找不到可「自訂主訴」（只寫進 CC，不帶題庫），任一已選主訴可「設為主訴」排在 CC 最前面。資料：`ed.custom`（fu：症狀→序號）、`ed.main`（sel：問題 id 或 `custom:<症狀>`）；標準問題與自訂主訴共用同一個選取序號。
- **問診深度**：精簡（只列★必問與已回答的題目，其餘收在「其他題目」）／標準／完整，預設精簡，選擇記在 localStorage `pe_note_ed_depth`（讀寫失敗就用預設）。特徵題（部位、性質、起病…）在所有深度都保留。
- **特別情境**（`special.ts`）：本次相關（救護車、酒醉、溝通困難、無家屬、OHCA）寫進 PI；長期背景（懷孕、哺乳、化療、免疫低下、抗凝血、管路、臥床、機構、近期手術、DNR）寫進 PH 的 `Situation:`。另有「問診補充」（PI 結尾）與每個 PE 欄位的自由補充（`ed.pex.<欄位>`）。
- **字數精簡**（`condense.ts`）：PI／PH 以「句」為單位，超過 ERS 上限時依重要性自動略過（分數：補充 100＞轉診 95＞本次情境 85＞必問陽性 80＞有細節的陽性 60＞一般陽性 50＞必問陰性 40＞一般陰性 10），鎖定的句子（使用者自己打的補充）永不略過；PE 沿用「完整→縮寫→正常項目合併」三段並可逐項「不寫入」。病歷輸出每欄有「逐句明細」，可勾選每一句寫不寫入（`ed.omit.<句 id>`：`omit`／`keep`），也可整體關閉自動精簡（`ed.ctx.autoFit` = `off`）。

## 2026-10-11：一個主訴、各自時間、緊湊版面、影像說明

- **CC 只寫一個主訴**（標★的那個）。其他已選症狀連同各自時間寫在 PI 開頭；同名問診題（例如「發燒」）不再重複，細節（Tmax）併進去。
- **每個主訴各自的時間**（`src/domain/ed/duration.ts`）：已選主訴列上的循環按鈕 TODAY → 2HOUR → 6HOUR → 12HOUR → 1D → 2D → 3D → 5D → 1W → 自訂 → 未標。存在 `ed.dur`（fu＝代碼、grp＝自訂文字）。舊的單一「主訴時間」`ed.ctx.duration` 只在主訴沒標時間時沿用。
- **循環按鈕**：問診有／無題一格一題（未答 → 無 − → 有 +），PE 一格一項（未查 → 正常 ✓ → 異常 !），TOCC 每格 (−)/(+)，問診深度也是循環。系統／PE 欄位名佔格子第一格，同一個格子流動排列；PE 欄位名點一下＝此欄未查的全標正常。一列 5 格（寬螢幕 8 格），不用裝飾性圓角框，只用色條與分隔線。
- **視情況再做的 PE** 全部收在一個 ▸；各欄自由補充也收在 ▸（有內容時自動展開）。病歷輸出的空白 PE 欄位收成「＋欄位」按鈕，ICD 未勾的候選收在 ▸。
- **TOCC 預設 (-)**：沒標 (+) 的一律寫 (-)。
- **特別情境**改為自由輸入（`ed.ctx.situation`，寫進 PH 的 `Situation:`），下拉選單插入常用片語；「本次相關情境」（救護車、酒醉…）移除。舊資料勾過的仍會輸出，畫面上可清除。
- **ICD 依答案更精確**：腹痛部位→象限碼、胸悶／壓迫→R07.89、活動喘／端坐呼吸、3 週內咳嗽→R05.1、否認嘔吐→R11.0、黑便／吐血、肢體左右（新增「哪一肢」題）、耳痛不再給喉嚨痛碼。規則欄位：`offWhenOptions`、`whenNo`／`offWhenNo`、`duration`（`types.ts`）。同一碼可由多條規則觸發。
- **必做 PE（★）減少**：每個問題最多 3 項（外傷 5 項），測試把關。
- **檢查**：CRP 改開 `9068010F CRP,`；不再建議 One touch（仍可手動加）。
- **影像說明**（`order-memo.ts`）：X 光與 CT／MRI 在 ORDERS 行尾多帶 `|診斷說明|檢查目的`（說明＝CC，目的＝依「檢查 × 問題」的 r/o 片語），給 ERS「請輸入說明」視窗；油猴腳本 4.6 起自動填入並在安全條件下按確認。
